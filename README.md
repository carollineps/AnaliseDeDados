# 📊 ANÁLISE DE DADOS

Dashboard interativo desenvolvido em Python e Streamlit para análise e visualização de dados.

O projeto apresenta informações de forma visual e interativa, permitindo analisar dados, comparar resultados e identificar os principais fabricantes e produtos.


#🚀 Tecnologias utilizadas

🐍 Python

📊 Pandas

📈 Plotly

🎨 Streamlit

🔧 Git e GitHub

#📌 Funcionalidades
Visualização de dados em gráficos interativos
Gráficos de linhas
Gráficos de barras
Gráficos de pizza
Ranking dos principais fabricantes
Análise do total por fabricante
Visualização dos produtos
Interface interativa através do Streamlit
Filtros e análise dos dados

#⚙️ Como executar o projeto
1. Clone o repositório
git clone https://github.com/carollineps/AnaliseDeDados.git
2. Entre na pasta
cd AnaliseDeDados
3. Instale as dependências
pip install -r requirements.txt

Caso ainda não tenha o arquivo requirements.txt, instale as principais bibliotecas:

pip install streamlit pandas plotly
4. Execute o Streamlit
streamlit run app.py

O sistema será aberto no navegador.

#🏆 Ranking

O projeto também apresenta um ranking dos fabricantes com base no total de dados analisados.

#🎯 Objetivo

O objetivo do projeto é transformar dados brutos em informações visuais e fáceis de interpretar, facilitando a análise e a tomada de decisões.
